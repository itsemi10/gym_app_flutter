💪 Gym Routine App (Flutter)

Aplicación móvil desarrollada en Flutter para gestionar rutinas de gimnasio de forma sencilla, visual y eficiente.

📌 Descripción

Esta aplicación permite a los usuarios crear y organizar sus rutinas de entrenamiento por días, agregar ejercicios con detalles específicos como series, repeticiones y peso, así como llevar un seguimiento del progreso.

El objetivo del proyecto es simular una app real de gimnasio, enfocándose en la experiencia del usuario, la organización del código y la implementación de funcionalidades útiles.

🚀 Características
📅 Creación de rutinas por día de la semana
🏋️ Gestión de ejercicios
📊 Barra de progreso de rutina
✅ Marcar ejercicios como completados
⏱️ Temporizador de descanso (60 segundos)
🧠 Notas personalizadas por ejercicio
💪 Registro de series, repeticiones y peso
🎨 Interfaz moderna con tema oscuro y tonos morados

🛠️ Tecnologías utilizadas
Flutter
Dart
Material Design

📦 Instalación
Clona el repositorio:
git clone https://github.com/itsemi10/gym_app_flutter.git
Entra al proyecto:
cd gym_app_flutter
Instala dependencias:
flutter pub get
Ejecuta la app:
flutter run

📱 Uso
Crea una nueva rutina seleccionando el día
Agrega ejercicios con sus detalles
Marca los ejercicios completados
Usa el temporizador de descanso entre ejercicios
Visualiza tu progreso en tiempo real
